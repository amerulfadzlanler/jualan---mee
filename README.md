# Sistem Jualan Mi Goreng (app)

Fail dalam folder ini: index.html, manifest.json, sw.js, icon-192.png, icon-512.png

## Letak di GitHub Pages
1. Daftar atau log masuk di github.com.
2. Tekan New repository, namakan contohnya `jualan-mee`, pilih Public, kemudian Create.
3. Tekan "uploading an existing file", seret SEMUA 5 fail (bukan zip), kemudian Commit changes.
4. Pergi Settings > Pages. Di Build and deployment, pilih Source: Deploy from a branch, Branch: main, folder / (root), kemudian Save.
5. Tunggu 1 hingga 2 minit. Link app: https://NAMA-GITHUB.github.io/jualan-mee/

## Pasang di telefon
- Android (Chrome): buka link, tekan menu (tiga titik), kemudian Pasang app atau Tambah ke skrin utama.
- iPhone (Safari): tekan butang Kongsi, kemudian Tambah ke Skrin Utama.

## Jadikan APK (pilihan)
Buka pwabuilder.com, masukkan link GitHub Pages awak, pilih Package for stores, kemudian Android.

## Data
Data disimpan dalam telefon sahaja. Guna Tetapan > Sandaran Data untuk simpan dan pulihkan salinan.
